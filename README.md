# MyBible / 多版本圣经阅读器

一个同时面向 **桌面与移动端** 的圣经阅读器，支持多版本对照、音频朗读与全文搜索。

A cross‑device Bible reader built for **desktop and mobile**, featuring parallel versions, audio playback, and full‑text search.

---

## ✨ 功能特点 / Features

- 📖 **多版本对照阅读**  
  多语言版本并列显示，方便比对原文与译文。

- 🔊 **音频朗读 + 经文高亮**  
  播放音频时自动高亮当前经文，支持连续阅读。

- 🔍 **全文搜索**  
  支持按书卷、章节及关键词检索。

- ⌨️ **桌面键盘快捷键**
  - `Space`：播放 / 暂停
  - `←`：快退 15 秒
  - `→`：快进 15 秒

- 📱 **移动端友好**
  - 自适应布局，手机 / 平板 / 桌面一致体验
  - 大按钮触控操作，适合朗读与翻阅

- 🇨🇳 **中文**：思高圣经（Studium Biblicum Version）
- 🌍 **English**：NRSVCE（New Revised Standard Version, Catholic Edition）
